Site Footprint Analysis

For each uploaded or manual site (all of them by default; tick the box below to restrict to Find Feeders matches), this pulls parcel + building footprint geometry to compute building area, lot area (geometry-computed and the assessor's recorded land sq ft), and outdoor area (lot − building) — all in ft². Building area comes from the national USA Structures layer (works anywhere). Lot/parcel data is pulled from county GIS for verified counties: Macon, Peoria, McLean, Madison, St. Clair, Vermilion, Adams, Coles, Morgan, Greene, Scott, Hancock, Henderson, McDonough, Jackson, Monroe. Some county servers refuse a browser request from a file opened directly; those rows fall back to building-only and say so. Elsewhere lot data isn't public, so only building area shows. Tip: run the dashboard through the Ameren_Server cell to unlock county data the browser otherwise blocks and to fill vendor-locked counties via ReportAllUSA.
Set Find Feeders params + click Search (or add a manual site), then “Analyze sites.”
Outdoor area = computed lot area − building footprint. A blank assessor column means the county record had no land-sqft field; the geometry-computed lot is the reliable figure. Multi-parcel sites are summed automatically.
